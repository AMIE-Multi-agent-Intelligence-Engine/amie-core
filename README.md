# AMIE
## Multi-agent Intelligence Engine

AMIE is an open-source platform for building modular intelligent systems through cognition, memory, knowledge, reasoning, planning, agents, workflows, governance, and enterprise integration.

### Status
Foundation release: `v0.1.0`

This repository is the engineering foundation. Major capabilities are introduced incrementally through the AMIE roadmap.

### Development
Python 3.11+ is recommended.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
pytest
ruff check .
```
